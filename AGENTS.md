This project is a ViteJS/React/TS UI + Blazor WASM (client) backend.
It is an in-browser IDE for C# (.NET).
The backend utilizes Roslyn APIs to store/compile/execute C#.
JS interop is utilized between UI and backend.
stackblitz.com would be an example - but this one is for C#.
Don't try to run the app yourself in the browser, or do dotnet run, npm run dev yourself.
